# 🚢 Titanic ML Project (End-to-End)

## 📌 معرفی پروژه
در این پروژه با استفاده از یادگیری ماشین، احتمال زنده ماندن مسافران کشتی تایتانیک پیش‌ بینی می‌شود.  
مدل با تحلیل ویژگی‌هایی مانند سن، جنسیت، کلاس مسافر، کرایه بلیت آموزش داده شده است.

پروژه‌ی Titanic یکی از معروف‌ترین مسائل Binary Classification در حوزه‌ی Data Science است و برای یادگیری کامل فرآیند ماشین لرنینگ بسیار مناسب می‌باشد.

---

## 🎯 هدف پروژه
- تحلیل داده‌های واقعی
- پیش‌ پردازش داده‌ها
- آموزش مدل‌های یادگیری ماشین
- پیش‌بینی زنده ماندن مسافران (Survived / Not Survived)

---

## 🧠 الگوریتم‌ها و روش‌ها
در این پروژه از الگوریتم‌های زیر استفاده شده است:
- Logistic Regression
- Random Forest
